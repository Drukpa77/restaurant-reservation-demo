# Demo-Web App

Restaurant reservation demo for a neighbourhood dining room in Braddon, Canberra.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port Next.js prints).

Demo bookings: `#RES1048` (table for 4) and `#RES1049` (group of 14). Look them up under Find booking.
